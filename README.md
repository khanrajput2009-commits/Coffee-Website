# Coffee Shop Website ☕✨

A modern, responsive, and elegant website for a coffee shop, built with HTML, CSS, and JavaScript.

## 🚀 Live Demo
Check out the live website here: 
[https://khanrajput2009-commits.github.io/Coffee-Website/](https://khanrajput2009-commits.github.io/Coffee-Website/)

---

## ✨ Features
* **Elegant UI/UX:** Clean, warm design tailored for coffee enthusiasts.
* **Interactive Menu:** Browse hot/cold coffees, snacks, and daily specials.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewports.

---

## 🛠️ Technologies Used
* **HTML5** - Markup structure
* **CSS3** - Layout styling and responsive media queries
* **JavaScript** - Interactive components and page behavior
